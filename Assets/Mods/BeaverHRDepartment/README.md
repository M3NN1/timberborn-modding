# Beaver HR Department

Assign individual beavers to workplaces.

## Features

- **Manual Assignment** — Click a building, pick which beaver works there
- **Remove Workers** — Unassign beavers and let the auto-system handle them

## How to Use

1. Click any workplace building
2. See the "Assignment" panel with current workers
3. Click "Assign Beaver" to see available unemployed beavers
4. Pick one — they'll start working there immediately
5. Click "X" to remove a worker from the building
